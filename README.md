# 北京·内官监查抄案 — 前厅 Demo

俯视 2D 叙事解谜，传统文化赛道 Demo。扮演查抄内官监织坊账料的小吏，在雨夜的前厅里观察器物、对照制度、自己读出那处「不对」。

**在线试玩**：打开本仓库的 GitHub Pages 首页即可（约 56 MB，首次加载需要一点时间）。

**Windows 下载**：[Releases](../../releases/latest) 里的 `NeiguanJian-windows-x64.zip`，解压后双击 `NeiguanJian.exe`，无需安装引擎。

## 操作

| 键 | 作用 |
|---|---|
| WASD / 方向键 | 八向移动 |
| `E` / `Enter` | 观察、推进对话、确认 |
| `Tab` | 随身手册（可并置两条对照） |
| `Esc` | 关闭面板 / 放弃谜题 |

流程约 2~3 分钟：读北墙告示与门牌 → 绕到官服背后看半印 → 开衣箱 → 在屏风旁小案填一道热身题 → 出口打开 → 结束卡。
